# Performance Optimization Recommendations

## Data Flow Efficiency
1. **Lazy Loading**: Load data only when needed
2. **Caching**: Keep frequently accessed data in memory
3. **Batching**: Group database operations
4. **Reactive Updates**: Only rebuild affected widgets
5. **Pagination**: Load results in pages instead of all at once
6. **Selective Watching (`select`)**: Watch only the part of provider state you need
7. **Debounce User Queries**: Prevent redundant DB/network calls when typing

## Memory Management
1. **Auto-Dispose Providers**: Use autoDispose with delayed eviction for soft caching
2. **Dispose Listeners/Subscriptions**: Clean up streams, animations, DB watchers
3. **Compact Models**: Use lightweight models for lists, load heavy data only on demand
4. **Cache with TTL**: Use time-to-live caches for recently accessed data
5. **Tight Provider Scopes**: Scope heavy providers to only the widgets/screens that need them

## UI Rendering
1. **Use Slivers & Virtualization**: Prefer ListView.builder/SliverList with itemExtent
2. **Stable Keys**: Use `Key` for list items to prevent rebuilds
3. **Avoid Expensive Layouts**: Minimize clipping, shadows, opacity layers
4. **Const Widgets**: Use const constructors where possible
5. **Image Optimization**: Resize images close to display size, use thumbnails

## Database Optimizations
1. **Indexes**: Add indexes for frequently queried fields (date, category, amount)
2. **Projection**: Query only needed columns
3. **Transactions**: Batch writes inside a single transaction
4. **Incremental Sync**: Sync only new/changed records instead of full table

## Concurrency & Background Work
1. **Isolates**: Offload heavy parsing/filtering to isolates
2. **Background Diffing**: Compute list diffs outside main thread
3. **Schedule Maintenance**: Run database cleanup, compaction, archiving in background

## Networking
1. **ETags & If-None-Match**: Prevent unnecessary re-downloads
2. **Compression**: Enable gzip/deflate on APIs
3. **Dedup Requests**: Avoid sending duplicate requests
4. **Retry with Backoff**: Gracefully handle transient network errors

## Animations & Frames
1. **Prefer Implicit Animations**: Use AnimatedContainer/AnimatedSwitcher
2. **Repaint Boundaries**: Wrap expensive widgets to isolate repaint cost
3. **Profile Frame Budget**: Ensure UI work stays under 16ms/frame

## Tooling & Guardrails
1. **Use Flutter DevTools**: Inspect timeline and memory allocations
2. **Heap Snapshots**: Compare memory before/after navigation
3. **Unit Test Selectors**: Ensure only minimal rebuilds happen
